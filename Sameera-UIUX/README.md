# Sameera Khan — UI/UX Design & Visual Architecture

## Project
Developer Portfolio & Case-Study Builder

## Role
UI/UX Design & Visual Design (`Sameera-UIUX/`)

## Contribution Overview
This directory contains the interactive UI/UX design system and visual prototype for the Developer Portfolio & Case-Study Builder. It establishes the theme architecture, typography tokens, responsive viewport behavior, and structured case-study layout used across the application.

## Features Demonstrated
- **Three Signature Themes:** Live switching between **Aurora** (dark glassmorphism), **Minimal** (editorial light), and **Neon** (cyberpunk terminal) styles.
- **Typography & Accent Tokens:** Dynamic Google Font switching (*DM Sans*, *Playfair Display*, *DM Mono*) and live accent color customization via CSS custom properties (`--user-accent`).
- **Responsive Viewport Switcher:** Instant preview across **Desktop (`100%`)**, **Tablet (`620px`)**, and **Mobile (`375px`)** containers.
- **Structured Case-Study Card:** Toggleable project showcase highlighting **01 · Problem** and **02 · Outcome** sections.

## Files
- `PortfolioDesign.jsx` — Interactive React component demonstrating theme switching, token controls, viewport toggling, and live preview.
- `PortfolioDesign.css` — Modular stylesheet defining layout grids, glassmorphism effects, theme tokens, and responsive breakpoints.
